---
name: Global character uniqueness
description: Gameplay rule for character availability and duplicate claims.
---

Character ownership is globally unique: once a character exists in any collection, it must not appear in future rolls and any outstanding roll for it must fail at claim time.

**Why:** The user chose a single-copy roster so collections do not accumulate duplicate character quantities.

**How to apply:** Preserve the existing collection records; do not silently delete or reduce historical quantities unless the user explicitly requests a data cleanup.
