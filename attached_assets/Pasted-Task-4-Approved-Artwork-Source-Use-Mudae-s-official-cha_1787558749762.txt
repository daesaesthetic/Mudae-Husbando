Task #4 — Approved Artwork Source

Use Mudae's official character database as the authoritative artwork source:

Mudae Character Database

The existing Mudae character browser provides exact character records including character name, series, gender, and associated character imagery.

Artwork sourcing rule

For the 12 verified characters currently present in our catalog:

Search for the exact character on mudae.net.
Confirm the character name matches.
Confirm the series matches.
Confirm the artwork depicts that exact character.
Use the corresponding publicly accessible image URL associated with that Mudae character.
Store that URL in the existing image_url field.
Important

Do not use:

Google/Bing image search results
unrelated image-hosting sites
random fan-art URLs
generic series images
another character from the same series
temporary/session-specific URLs
Discord attachments
locally hosted images

Mudae's character database should be treated as the preferred and authoritative artwork source for this task.

The goal is to make our character cards visually correspond to the characters represented in Mudae while keeping our own database and gameplay systems independent.

Exact-character verification

Do not match based on name alone.

For each character verify:

      ↓

If a character has an alias or naming difference, use the Mudae record only after confirming it is the same character.

Image URL stability

Before storing an image URL, verify that it is actually usable by our Discord embed implementation.

If Mudae exposes the image through a stable public URL, use that URL.

If the Mudae website's displayed image is loaded through a mechanism that does not provide a stable directly usable public image URL, do not invent or guess the underlying URL.

In that situation, report the specific character and the technical limitation instead of inserting a broken URL.

Do not introduce a scraping system just to work around this.
