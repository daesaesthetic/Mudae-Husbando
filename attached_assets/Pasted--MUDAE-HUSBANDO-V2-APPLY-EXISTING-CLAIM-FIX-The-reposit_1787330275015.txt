## THE BUG

The current claim authorization incorrectly requires the user attempting to claim a roll to be the same user who created the roll.

The current behavior is effectively:

    User A uses /roll
        ↓
    User B clicks Claim Character
        ↓
    "Only the user who rolled this character can claim it"

THIS IS WRONG.

## REQUIRED GAMEPLAY RULE

Rolls are PUBLIC.

Anyone who can access the roll message may attempt to claim the character.

The first successful claim wins.

Example:

    User A
      ↓
    /roll
      ↓
    Sasuke Uchiha appears
      ↓
    User B clicks Claim Character
      ↓
    User B receives Sasuke

User A does NOT have priority merely because User A rolled the character.

If User A claims first:

    User A receives Sasuke.

If User B claims first:

    User B receives Sasuke.

After the first successful claim, everyone else receives an already-claimed response.
