CURRENT MILESTONE 2 CONTEXT
==================================================

The current V2 Milestone 2 implementation has been manually tested in Discord and is considered FUNCTIONALLY VALIDATED.

Known working gameplay includes:

- verified-character rolling
- /roll
- persistent rolls
- Discord character cards
- public Claim Character buttons
- /claim
- transactional claiming
- first-claim-wins behavior
- persistent ownership
- duplicate character ownership
- roll expiration
- Discord integration

The intended gameplay rule is:

A user who rolls a character does NOT automatically own that character.

A roll is publicly claimable.

The first successful claimant receives the character.

The system therefore intentionally distinguishes:

rolled_by

from:

claimed_by

These may be different Discord users.

Example:

rolled_by  = User A
claimed_by = User B

is completely valid.

DO NOT modify this behavior.
