# 6. CLAIM AVAILABILITY MUST BE SEPARATE FROM CHARACTER OWNERSHIP

There are two different concepts:

### Character ownership

```text
Who owns this specific character?
```

The existing global uniqueness/claim transaction remains authoritative.

### User claim availability

```text
Can this user perform another claim right now?
```

The current bug is related to the second concept.

Do not conflate these.

The fix must not weaken or bypass:

* advisory locks
* ownership checks
* first-claim-wins behavior
* expiration checks
* verified-character checks
* claim transaction safety


The only thing that changes is their ability to claim again.
